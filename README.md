# CV — Cruz Yael Pérez González

Personal CV site built with React 19, Vite, and the [Astryx](https://github.com/meta/astryx) design system.

## Development

```bash
npm install
npm run dev
```

## Editing content

All CV content lives in `src/data/cv.ts`. Layout is in `src/App.tsx` and styles in `src/index.css`.

## Build

```bash
npm run build   # outputs to dist/
```
